# MSN Messenger AI — Resurrection Spec (Kiroween 2026)

## Concept
Resurrect MSN Messenger (the legendary 2000s IM client) as a modern web app where AI contacts
live in your buddy list and chat with you. Built for the Kiroween "Resurrection" category —
reviving dead tech with new life.

## Features
- Classic MSN UI: buddy list with display pictures, statuses (Online/Busy/Away/Appear Offline)
- Chat windows with "X is typing..." indicator, nudges (Ctrl+G), winks, emoticons
- AI contacts: Gemini-powered bots that actually converse (Firebase AI Logic or direct Gemini API)
- Sign-in screen replica with the iconic "Signing in..." sound-era aesthetic
- Display name personalization, custom emoticons
- The dead tech comes alive: 2005 UX + 2026 AI

## Stack
- Pure HTML/CSS/JS (no framework — nostalgic simplicity)
- Gemini API for AI contacts (server-side key via env on deployed host)
- Deploy: static hosting

Specs written in .kiro/specs/, app built with Kiro Crew assisting development.
